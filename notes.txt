7. Staging Environment -> The staging environment (or staging area) is like a waiting room for your changes

      some key commands for staging
      ****************************************

      git add <file> -----> Stage a file
      
      git add --all     or     git add -A ----> Stage all changes
      
      git status ------> See what is staged
      
      git restore --staged <file> -----> Unstage a file

     ******************************

Day 3 

Git merge conflict
*********************

Step 1: Initialize a Local Repository
******************************************
mkdir git-conflict-exercise
cd git-conflict-exercise
git init

Step 2: Create a Base File
*******************************
echo "Line 1: This is the original text." > project.txt
git add project.txt
git commit -m "Initial commit"

Step 3: Create a New Branch & Make a Change
***********************************************************
note -> Create and switch to a new branch named feature-branch. Modify Line 1 and commit the change

git checkout -b feature-branch
echo "Line 1: Feature branch modified this text." > project.txt
git add project.txt
git commit -m "Modify line 1 on feature branch"

Step 4: Switch Back to Main & Make a Conflicting Change
*********************************************************************
note ->Switch back to your main branch. Modify the exact same line of the same file with a different sentence to create a direct conflict

git checkout main
echo "Line 1: Main branch changed this text differently." > project.txt
git add project.txt
git commit -m "Modify line 1 on main branch"

Step 5: Trigger the Conflict
********************************
git merge feature-branch

Step 6: Resolve the Conflict
*********************************
 open project.txt -> conflict markers inserted by Git

The Fix:

Manually edit the file to keep the final text you want, and delete all the conflict markers (<<<<<<<, =======, >>>>>>>).


Step 7: Finalize the Merge
*******************************
git add project.txt
git commit -m "Resolve merge conflict by combining changes"

Phase 1: Create a Repository on GitHub
**************************************************
1. Open your browser and go to GitHub.
2. Log in and click the "+" icon in the top right corner, then select New repository
3.e.g., git-conflict-exercise
4.Click Create repository.

Phase 2: Link and Push Your Local Code
************************************************
git branch -M main

git remote add origin https://github.com

git push -u origin main
